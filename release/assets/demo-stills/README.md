# Screenshot thumbnail source

The finished screenshot composition is [`../thumbnail-screenshots.png`](../thumbnail-screenshots.png), exported from Figma at 1920 × 1080 in sRGB.

[Edit the composition in Figma](https://www.figma.com/design/BMqc0z8FUhrcWrjM2G5wkj/Description-Generator-Community-Thumbnail?node-id=2-2).

The headline and supporting copy are editable text. The interface and component set are image layers containing original frames extracted from `specs/demo.mp4`; the Figma file also retains the full source frames.

- `descriptions-01m31s.png`: plugin crop starts at x=364, y=157, width=920, height=804.
- `descriptions-01m31.8s.png`: the same interface state; its lower portion from y=450 replaces the corresponding portion of the first frame to exclude the moving cursor. All interface pixels come from the recording.
- `components-01m38s.png`: component context crop starts at x=455, y=280, width=620, height=536.

`../thumbnail-demo-concept.png` and `thumbnail-prompt.txt` belong to the earlier imagegen exploration. They are not used in the Figma composition.
