# Security policy

This policy covers the latest released Description Generator plugin and its currently deployed backend service on Cloudflare Workers.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/panoptican/figma-description-generator/security/advisories) and select **Report a vulnerability**. A GitHub account is required. Please do not report security vulnerabilities in public issues.

Include a description of the issue, steps to reproduce it, and the potential impact. Use a test file where possible. Do not include API keys, payment tokens, personal information, or confidential design files.

## How reports are handled

The maintainer reviews the report, assesses its impact, and prioritizes a fix or mitigation based on severity. The private report is used for follow-up questions and progress updates.

Confirmed issues are addressed through a plugin update or backend deployment. If needed, an affected feature may be temporarily disabled while a fix is prepared. The maintainer checks the fix and coordinates any public disclosure with the reporter after a mitigation is available.

Response and resolution times depend on the issue; there is no guaranteed deadline.

For ordinary bugs or feature requests, use the [public issue tracker](https://github.com/panoptican/figma-description-generator/issues).
